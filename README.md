# Birr Track website

Static site for the Birr Track Android app, published with GitHub Pages at
https://kaleabolanizo.github.io/birr-track-web/

- `/` — about the app
- `/privacy/` — privacy policy (the URL used in the app and in Play Console)
- `/terms/` — terms of use

Plain HTML and one stylesheet (`assets/style.css`); no build step, scripts or trackers.
The privacy policy text mirrors `docs/play-store/privacy-policy.md` in the app repository; update both together.
